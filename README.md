# chtracking — учёт расходов

Простое веб-приложение для учёта расходов относительно базовой суммы **£2600 в месяц**,
которая поступает **22-го числа** каждого месяца.

Никакого сервера и базы данных — один HTML-файл, всё хранится в `localStorage`
вашего браузера.

## Как пользоваться

Просто откройте `index.html` в браузере (двойной клик) — либо включите
GitHub Pages для этого репозитория (Settings → Pages → Deploy from branch → `main` / `/`),
и приложение будет доступно по ссылке `https://<username>.github.io/chtracking/`.

## Что умеет приложение

- **Период** = отрезок от даты поступления денег (по умолчанию 22-е число) до
  дня перед следующим поступлением. Можно листать периоды стрелками ‹ ›.
- **Добавление транзакций**: дата, сумма (£), комментарий на что потрачено.
  Отрицательная сумма считается возвратом/поступлением и увеличивает остаток.
- **Итог по периоду**: бюджет периода, перенос остатка с прошлого периода,
  сумма потраченного, остаток — остаток автоматически переносится
  на следующий период (может быть и положительным, и отрицательным).
- **Обзор по периодам**: таблица со сводкой по всем месяцам, клик по строке
  открывает этот период.
- **Настройки**: базовая сумма в месяц, день поступления средств, начальный
  остаток (если нужно начать не с нуля).

## Данные

Все транзакции и настройки хранятся локально в браузере (`localStorage`),
ничего никуда не отправляется. Если нужно перенести данные на другое
устройство — экспорт/импорт можно добавить позже по необходимости.
